# گردش‌کار مستقل n8n: گزارش وظایف NEXUS

فایل قابل ورود به n8n: `n8n/workflows/nexus-gallery-open-tasks.json`

## چه می‌کند؟
- با اجرای دستی شروع می‌شود.
- وظایف باز پروژه `golddyousefi` را از `GET /api/tasks?project=golddyousefi&status=open` می‌گیرد.
- گزارشی فارسی شامل تعداد وظایف، عنوان، اولویت، موعد و وضعیت می‌سازد.
- این گردش‌کار عمداً غیرفعال و دستی است؛ هیچ پیام یا اعلان خارجی نمی‌فرستد و چیزی را تغییر نمی‌دهد.

## وارد کردن در n8n
1. در n8n از منوی Workflows گزینه Import from File را انتخاب کن.
2. فایل `n8n/workflows/nexus-gallery-open-tasks.json` را وارد کن.
3. روی «اجرای دستی گزارش» بزن و خروجی نود «ساخت گزارش فارسی» را ببین. مقدار گزارش در فیلد `report` است.

## پیش‌نیاز اتصال شبکه — مهم
در Compose فعلی، n8n داخل کانتینر اجرا می‌شود اما API روی ویندوز میزبان اجرا می‌شود. آدرس `host.docker.internal` برای رسیدن از کانتینر به میزبان است؛ با این حال `apps/api/src/main.ts` فعلاً API را فقط روی `127.0.0.1` گوش می‌دهد. بنابراین گردش‌کار تا وقتی این مرز شبکه به‌صورت امن اصلاح نشده، ممکن است با خطای اتصال مواجه شود.

**این فایل به‌تنهایی اتصال را برقرار نمی‌کند و هنوز در نمونه n8n محلی کاربر import یا اجرا نشده است.** API را بی‌محافظ روی `0.0.0.0` باز نکن؛ این کار ممکن است دسترسی شبکه‌ای ناخواسته ایجاد کند. راه‌حل ترجیحی، اجرای API در همان شبکهٔ خصوصی Docker Compose و درخواست از آدرس داخلی سرویس است؛ قبل از آن باید پیکربندی build، محیط و مهاجرت‌های API به‌درستی آماده و آزمایش شود.

## حریم داده
- فقط وظایف باز پروژه گالری را می‌خواند.
- از اعتبارنامه یا سرویس خارجی استفاده نمی‌کند.
- داده‌ای نمی‌نویسد، حذف نمی‌کند یا منتشر نمی‌کند.
