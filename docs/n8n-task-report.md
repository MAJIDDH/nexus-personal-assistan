# گردش‌کار مستقل n8n: گزارش وظایف NEXUS

فایل قابل ورود به n8n: `n8n/workflows/nexus-gallery-open-tasks.json`

## چه می‌کند؟
- با اجرای دستی شروع می‌شود.
- وظایف باز پروژه `golddyousefi` را از `GET /api/tasks?project=golddyousefi&status=open` می‌گیرد.
- گزارشی فارسی شامل تعداد وظایف، عنوان، اولویت، موعد و وضعیت می‌سازد.
- این گردش‌کار عمداً دستی است؛ هیچ پیام یا اعلان خارجی نمی‌فرستد و چیزی را تغییر نمی‌دهد.

## اتصال خصوصی سرویس‌ها
در Compose، API و n8n در شبکهٔ داخلی Docker قرار می‌گیرند. نود HTTP از نام سرویس `http://api:3000` استفاده می‌کند. API فقط با نگاشت `127.0.0.1:3000:3000` روی loopback میزبان منتشر می‌شود؛ دسترسی سرویس‌به‌سرویس از شبکهٔ داخلی Compose است. اجرای API مستقیماً روی ویندوز همچنان به‌طور پیش‌فرض روی `127.0.0.1` گوش می‌دهد. مقدار `HOST=0.0.0.0` فقط در کانتینر API تنظیم شده است.

## راه‌اندازی پیشنهادی
1. از تغییرات این PR پس از بررسی استفاده کن؛ PR هنوز ادغام نشده است.
2. در پوشهٔ ریشهٔ پروژه، اجرا کن:
   `docker compose config`
3. اگر API قبلاً روی ویندوز به‌صورت `npm run start:dev` اجراست، آن را با `Ctrl+C` متوقف کن تا پورت 3000 آزاد شود.
4. اگر پیکربندی بدون خطا نمایش داده شد، برای ساخت و راه‌اندازی سرویس‌ها:
   `docker compose up -d --build postgres api n8n`
5. بررسی وضعیت:
   `docker compose ps`
   و سپس از ویندوز بررسی کن:
   `Invoke-RestMethod http://127.0.0.1:3000/api/health/ready`
6. در n8n از منوی Workflows گزینهٔ Import from File را انتخاب و `n8n/workflows/nexus-gallery-open-tasks.json` را وارد کن.
7. اجرای دستی را بزن و خروجی نود «ساخت گزارش فارسی» را بررسی کن؛ گزارش در فیلد `report` است.

## نکات مهم
- این تغییرات هنوز روی Docker Desktop محلی کاربر اجرا یا تأیید نشده‌اند. ابتدا `docker compose config` و سپس build/health check را انجام بده.
- API container از همان volume دیتابیس محلی استفاده می‌کند و مهاجرت‌ها را پیش از شروع API اجرا می‌کند. دادهٔ آزمایشی موجود در volume حفظ می‌شود؛ پیش از هرگونه حذف volume از آن استفاده نکن.
- رمزهای Compose فقط برای توسعهٔ محلی هستند؛ سرویس را به اینترنت یا شبکهٔ عمومی منتشر نکن.
- این گردش‌کار فقط داده را می‌خواند؛ هیچ تغییر یا حذف در وظایف انجام نمی‌دهد.
