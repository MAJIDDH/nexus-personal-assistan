# NEXUS — Personal Assistant

NEXUS is a personal-assistant project intended to grow into a modular, secure assistant for conversations, business workflows, and scheduled tasks.

## Status

Project initialization. Features are not considered complete until implemented and tested.

## Principles

- Start with a modular monolith.
- Keep secrets and real environment files out of version control.
- Require explicit confirmation for sensitive or irreversible actions.
- Prefer low-cost, replaceable providers and integrations.
